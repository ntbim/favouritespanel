Favourites Panel

A sleek dockable panel for Autodesk® Revit® to bookmark and quickly access your most-used Views, Modeling types, and Families.

Key Features

  • Quick Access Favorites: Bookmark views, sheets, families, line styles, and filled regions with a single click.
  • Instant View Activation: Open views immediately by double-clicking.
  • Smart Type Swapping: Change selected element types directly from the panel.
  • Auto-Highlighting: Automatically highlights compatible favorites when model elements are selected.

Workflow & Usage Guide

1. Initial Setup and Accessing the Panel

After installing the plugin, launch Autodesk® Revit®. Navigate to the top Ribbon menu and click on the Add-ins tab. Look for the Favourites panel and click the Favourites Panel button. This displays the custom dockable tool panel on the right side of your screen by default. You can drag and dock this panel anywhere within your Revit interface to suit your personal workspace layout.

2. Adding Favourite Items

You can quickly populate your favorites list using two simple methods:

  • Active View Bookmark: If no elements are selected in your model, simply click the Add button on the top bar of the Favourites panel. The current active view or sheet will be instantly added under the Views section.
  • Element Selection Bookmark: Select one or multiple elements in your model viewport or Project Browser (such as Walls, Doors, Windows, Detail Lines, Text Notes, or Filled Regions), and click the Add button. The plugin automatically categorizes the selected item into the Modeling or Families sections and applies color-coded visual badges.

3. Interacting with Favorites (Double-Click Actions)

  • Opening Views: Double-clicking any favorited item under the Views section will immediately set that view or sheet as your active viewport.
  • Changing Element Types (Type Swapping): Select any existing element in your Revit model space, then double-click a favorited type in your list. The plugin will execute a transaction to swap the selected element's type to your favorite choice and present a brief confirmation overlay.
  • Create Similar Tool: If no elements are currently selected in the model, double-clicking any favorited model type or family will instantly launch Revit's native Create Similar command, allowing you to start placing new instances immediately.

4. Automatic Selection Highlighting

When you select any element in your active Revit model, the Revit Favourites panel automatically evaluates the selection. Any matching or compatible favorite item in your panel will immediately highlight with a distinct blue border, while non-compatible items are slightly faded. This gives you instant visual feedback on which favorited styles or types can be applied to your current selection.

5. Context Menu & Batch Selection

Right-clicking any item in the Favourites list opens a context menu with enhanced functions:

  • Select All Instances: Selects every instance of the favorited type across the entire project model.
  • Select All Instances in View: Selects only the instances visible within the active view.
  • Remove Item: Deletes the specific item from your favorites list.

6. Managing & Removing Favorites

To remove items, select the item in the list and click the Remove button at the top of the panel, or use the red Remove All buttons located inside each category header for batch clearing.

All configuration data is stored locally per project in %AppData%\FavouritesPanel without modifying your actual .rvt file.
